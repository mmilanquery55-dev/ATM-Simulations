ATM Simulation System – Working Process



The ATM Simulation System is a simple Python-based banking application that simulates the basic functions of a real ATM machine.
This project allows users to:

Verify ATM PIN
Check account balance
Deposit money
Withdraw money
Exit the system safely

The project uses:

Conditional statements (if-elif-else)
Loops (while)
Exception handling (try-except)
Variables and user input
